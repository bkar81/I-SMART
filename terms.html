What I-SMART is

I-SMART (Image & Screenshot Markup, Annotation & Redaction Tool) is a client-side web application for opening or pasting images, creating editable annotation Layers, refining them and exporting the result. I-SMART is provided as a Progressive Web App.

Your images and configuration

I-SMART processes images in the browser. You are responsible for the images you open, the annotations you create, the accuracy of redaction or other edits, and for keeping backups of important settings or exported results.

Export and sharing

Exporting or sharing an image is initiated by you. You are responsible for choosing the correct destination, file format and information to share.

Browser capabilities

Clipboard access, EyeDropper support, PWA installation and other browser capabilities depend on the browser, device and hosting context. I-SMART cannot guarantee that every browser feature will be available everywhere.

Backup and reset

I-SMART provides JSON export and import for tool settings. Resetting tool settings restores the factory tool profiles and does not alter existing Layers. Clearing browser site data may remove locally stored I-SMART preferences.
